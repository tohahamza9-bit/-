# خطة تنفيذ بوت MONEYADO — تقسيم المراحل والوكلاء

هذا الملف هو خريطة الطريق التنفيذية. يقابل المواصفات في `مواصفات_بوت_MONEYADO_للتنفيذ.md`.

## المبدأ الحاكم
> لو شكّيت — لا تُنزّل. علّق ⚠️، نبّه (Reply)، وكمّل. البوت لا يوقف الطابور، ولا يُنزّل غلط.

## البنية التقنية المعتمدة
- **whatsapp/** — خدمة Node.js (Baileys) للقراءة والالتقاط + الإرسال المقيّد (whitelist §2.2).
- **core/** — خدمة Python (FastAPI): الفهم، الطابور، التجميع، المطابقة، الكُتّاب، التحقّق، الحارس، الأنبوب.
- **dashboard/** — واجهة ويب (FastAPI + HTML/JS) للتحكّم والإدارة (§13).
- **MongoDB** — مصدر الحقيقة (طابور + دفتر).
- **SQL Server** — تحقّق قراءة فقط (pyodbc).
- **pywinauto** — RPA على شاشتَي «بيع/شراء عملة».

## العقود المشتركة (يبنيها الأساس — لا يغيّرها أي وكيل)
- `core/models.py` — نماذج البيانات + التعدادات (Enums).
- `core/constants.py` — العملات، الخزائن، العلامات، الحالات.
- `core/db.py` — مستودعات MongoDB.
- `core/config.py` — الإعدادات (env).
- `core/writers/base.py` — واجهة الكاتب القابل للتبديل.
- `core/bus.py` — واجهة الإرسال المقيّدة (whitelist).

## المعلّقات التقنية (ملحق ب) — placeholders قابلة للإعداد
1. `auto_id` لكل خانة (شاشتا بيع/شراء) → `config/moneyado_fields.example.json`.
2. أسماء جداول SQL → `config/sql_queries.example.json`.
3. أكواد خزائن (هادم/خصم1%/صافي/تونسي خارجي) → إدارة من Dashboard.
4. معرّفات الغرف → env + Dashboard.
